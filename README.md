# 拾词 · CET-6 学习空间

基于 React 19、TypeScript、Vite 和 Express 5 的个人英语六级练习网站。试卷、答卷和单词本保存在本地 SQLite 数据库。

## 获取源码与启动

需要 Node.js 22.13 或更新版本。服务端主要面向 Linux / WSL；`npm start` 使用 POSIX 环境变量语法。PDF 导入另需系统工具，见 [PDF 导入与分享说明](docs/pdf-import-sharing.md)。

```bash
git clone https://github.com/cccht/English_learn_web.git
cd English_learn_web
npm ci
npm run dev
```

公开仓库只包含程序源码、界面素材、原创示例题和自制测试夹具；不包含真实账号、个人学习数据、AI API Key、访问凭据、下载的第三方试卷或软件著作权申请资料。首次启动会在本机创建自己的数据库。

开发前端默认使用 `http://localhost:5173`；端口已占用时 Vite 自动选择下一个可用端口，实际地址以终端输出为准。后端默认使用 `http://127.0.0.1:3001`，启动前请确认该端口未被其他实例占用。没有访问配置的开发实例不得映射至公网。

生产构建与本地运行：

```bash
npm run build
npm start
```

构建后，后端直接提供前端静态文件，可打开 `http://127.0.0.1:3001`。当 `data/public-access.json` 存在或设置了 `SHICI_ACCESS_FILE` 时，自动启用独立账号登录与注册。没有访问配置时仅适合本机开发使用。

## 账号与管理员

新部署如需启用账号登录，先生成自己的访问配置，再启动服务：

```bash
node scripts/setup-public-access.mjs
```

脚本随机生成初始密码与会话密钥，写入本机 `data/public-access.json`，并在 `data/public-access.txt` 保存登录说明；已有配置不会被覆盖。初始管理员账号为 **`admin`**，初始密码见该私有说明文件。第一次带访问配置启动时自动创建管理员；以后启动不会覆盖已经设置的密码。请勿提交或分享这两个文件。

未登录时，`/` 默认启用基于 **[huangbai-scrolling](https://github.com/huangbai-AI/huangbai-scrolling)** 规范打造的沉浸式视差滚动空间（`public/scrub-engine.js` 与 `public/home-scroll.css`），将拾词的品牌故事做成随滚动推进镜头的连贯体验：

- **5 幕连续叙事旅程**：专注空间（研习小屋起点） $\rightarrow$ 分屏真题（考场全真作答） $\rightarrow$ 随写批注（思考痕迹与压感笔触） $\rightarrow$ 生词语境（词不离句与翻卡记忆） $\rightarrow$ 笃定前行（智能诊断与行动入口）。
- **镜头时间重映射与无缝逐帧控制**：由滚动距离驱动画面景深推进，未加载视频时对高画质 WebP 海报进行 Ken-Burns 景深平滑缩放与交叉淡化；生成短视频后只需放入 `public/videos/` 并配置路径，即可由引擎通过 Blob 内存换帧逐帧穿行。详细的 Seedance 2.5 视频镜头生成提示词及编码标准见 [`docs/design/scrolling-scenes-prompt.md`](docs/design/scrolling-scenes-prompt.md)。
- **双视图切换与无障碍降级**：右上角提供「图文详情 / 沉浸漫游」双向切换，底层保留完整的语义化 HTML 降级结构（`<section class="feature-section" id="...">`、`#practice`、`#notes`、`#review` 原生锚点），无脚本时仍可顺畅浏览图文。系统开启「减少动态效果」时自动停用粒子并改用极简静态淡入淡出。
- **全闭环认证联动**：视界内的所有行动按钮与顶部导航直接与现有的玻璃拟态登录/注册弹窗无缝联动，登录仅需账号与密码；已登录用户访问 `/` 仍直接进入个人学习空间。首页严格保护隐私，不读取或展示个人学习数据。

管理员登录后进入左侧「管理后台」，可切换「开放新账号注册」。默认开放注册；关闭后，注册入口与直接 POST 注册都会被限制，包括关闭前已打开的注册表单，但已有账号仍可登录。注册只能创建普通学习账号，不能自行指定管理员角色。

管理后台可停用或恢复普通账号。停用后已有登录会话失效，学习数据保留；恢复后需要重新登录。管理员账号不能被停用。所有账号都可以通过右上角钥匙按钮修改密码，修改后所有旧会话失效。

账号密码采用独立随机盐的 scrypt 哈希存储。账号不区分大小写，长度为 3–32 位，允许字母、数字、下划线、点和连字符；密码长度为 10–128 位。

从旧版单用户实例升级时，原有试卷、答卷、单词本、AI 配置和报告归管理员 `admin`。新账号只能读取自己的作答、词汇、导入试卷和 AI 数据；内置试卷供所有账号使用。升级前请自行备份 `data/`；公开仓库不包含任何生产备份。

普通账号的 AI 服务地址由管理员在后台统一指定，普通账号填写自己的模型名和 API Key，不能访问其他任意地址或擅自调用本机模型。管理员自己的 AI 配置保持独立。管理员改变普通账号的服务来源时，旧来源的密钥会清除，避免被发送到新的服务。

## Cloudflare Tunnel 公网访问

公网访问是可选部署方式，不会因克隆仓库自动启用。启用前必须运行上述访问配置脚本，并确认登录保护已生效。

- 可移植的 systemd 示例位于 `deployment/*.service.example`，使用方法见 [部署示例](deployment/README.md)。示例以 `/opt/shici` 为安装目录，路径、运行用户与可执行文件位置应按部署机器调整；本机实际服务配置不随仓库公开。
- 临时 Tunnel 启动器是 `scripts/run-tunnel.mjs`，默认调用 `/usr/local/bin/cloudflared`，连接 `http://127.0.0.1:3001`。需自行安装 Cloudflare 客户端并核对该路径。
- Tunnel 启动后，地址写入本机 `data/tunnel-status.json`，登录说明保存在 `data/public-access.txt`。临时地址在 Tunnel 重启后可能变化。
- `data/public-access.json` 的 `password` 仅用于首次创建管理员；后续通过网页修改账号密码。`sessionSecret` 用于会话签名，`publicOrigin` 用于校验公网来源。配置文件、数据库、备份与访问说明均已被 `.gitignore` 排除。
- 本机、WSL 与网络需要保持运行。停止自己部署的服务前应先确认服务名，避免操作其他项目。

公网会话使用 HttpOnly、Secure、SameSite=Strict Cookie，有效期 7 天。模型配置、学习记录和导出接口需要登录。临时域名的工作方式见 [Cloudflare Quick Tunnels 官方说明](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)。

## iPad、手机与文章批注

答题页右上方可选择自动、电脑、iPad 或手机模式，选择按账号保留在当前浏览器。iPad 横竖屏均为左右各 50%：左侧文章与批注，右侧题目和选项，各自独立滚动。手机在「文章与批注」「作答」之间切换，顶部倒计时、大题用时和答题进度始终可见；次要说明折叠，答题卡按需打开。

文章上可用触笔直接书写；钢笔、荧光笔、整笔橡皮擦、撤销与重做在文章工具栏。设置内提供颜色、笔宽、手指书写、文字备注、缩放、清空和 JSON 导出。默认手指用于拖动文章，双指缩放；开启「手指书写」后手指也可画线。鼠标可使用相同工具。触笔压力通过 Pointer Events 采集，实际笔压与防误触效果取决于设备和浏览器；尚未用实体 iPad / Apple Pencil 验证。

批注按账号、答卷和题组隔离，交卷后可在逐题解析中打开「查看文章与批注」。笔迹使用固定 720 单位纸张坐标和本地字体，改变窗口大小不会重排文章或移动笔迹。网络正常时保存到 SQLite，编辑同时写入 IndexedDB 本机草稿；断网时保留已载入文章的草稿，恢复连接后重试同步。首次打开尚未缓存的页面仍需联网。多个设备发生版本冲突时需要明确选择版本，处理前会保留本机备份，不自动覆盖。

每篇上限为 1,500 笔、150,000 个采样点、单笔 5,000 点及 10,000 字文字备注。JSON 导出包含原文、纸张尺寸、笔迹坐标和文字备注，目前不提供手写识别、PDF 导出或 JSON 导入。清除浏览器存储会删除尚未同步的草稿，应先同步成功或导出。批注不会加入答案、评分或 AI 分析输入。

## 学习诊断与 AI

打开「学习诊断」，可选择近 30 天、90 天或全部记录。统计自动关联已交卷答卷、试卷题型和当前单词本：

- 区分听力长对话、短文、讲座，以及选词填空、长篇匹配、仔细阅读。正确率和错误率只以实际作答的客观题为分母，未答题单列。
- 同一题反复出错时汇总作答次数、错因和最近一次结果，能返回原报告核对。不同试卷的同名题目不会被合并。
- 新练习记录已保存的选项改答、大题切换，以及临近截止时的修改；旧记录缺失的行为数据会明确标注。分项计时包含离开页面的时间，不等于专注时长。
- 单词本可标记「从没学过、学过但忘了、熟词僻义、看得懂但听不出、形近词混淆、搭配不熟悉」。复习时的「已掌握／没记住」反馈会保存历史；重复收录也保留每次语境。
- 词汇与错题材料的共现仅作为线索，不直接视为答错原因。样本少、反复做相同原题或未经真题等值校准时，报告会说明限制。

按本次选择，AI 默认使用兼容 OpenAI 的 Chat Completions API。在「模型设置」填写 Base URL、服务方提供的模型名和 API Key，再点击「生成 AI 分析」。Base URL 通常应包含 `/v1`，不要填写整个 `/chat/completions` 路径。也支持切换到本机 Ollama。

API Key 只保存在本机数据库，不会通过配置读取接口、报告或导出返回。生成时会将统计摘要、部分重点错题及生词语境发送至所配置服务。普通统计不联网；AI 报告会验证返回格式和证据编号，生成失败时显示实际错误，不以固定文案冒充模型结果。

AI 解读包括可能原因、验证练习与 1 至 7 天的学习计划，并保留对应证据快照。更新错因、单词原因或完成新练习后，旧 AI 报告会显示数据已更新，可重新生成。服务重启会保留已有报告，并将未完成任务标为中断。

AI 页的「分析记录」可切换最近 30 份报告；生成失败后仍能返回之前的成功报告。诊断可以导出为包含题型统计、词汇原因、学习计划和证据快照的 Markdown 文件。

也可通过启动进程的环境变量为管理员提供默认设置：`SHICI_AI_PROVIDER`（`openai-compatible` 或 `ollama`）、`SHICI_AI_BASE_URL`、`SHICI_AI_MODEL`、`SHICI_AI_API_KEY`。已在页面保存的设置优先；普通账号不继承这些密钥，应用不会自动读取其他项目的密钥。

## 题库内容

现已支持 PDF 导入：文字提取或扫描页 OCR 后，对照原页校对题目、选项、答案和分值，确认后即可进入原有作答流程。原 PDF 和校对草稿保留；缺少标准答案的题目采用人工评分，不会被自动算错。

题库管理支持多选、全选 PDF 试卷并创建分享链接或分享码。接收者登录后可选择导入，获得独立副本；重复导入不覆盖已有内容。创建者可设置有效期并撤销分享，答卷、批注、单词本和 AI 设置不会随试卷分享。识别边界、依赖、限额与验证说明见 [PDF 导入与分享](docs/pdf-import-sharing.md)。

当前内置 1 套完整原创模拟卷，包含 57 题：写作 1、听力 25、阅读 30、翻译 1。另有 4 个已核验的历史真题来源入口，年份和考次均有来源记录。历史真题全文未打包，不能直接作答；可通过「题库管理」导入自己持有的完整真题内容。

导入流程：下载试卷模板，填入题目、选项、答案、解析和参考范文，使用新的唯一 `id` 导入。模板是 2 题、70 分钟的小样，演示数据结构；请将总时长、分题权重、各大题与题目一并改成你的真实试卷。所有题目 `weight` 之和必须为 100。导入操作不覆盖已有试卷。来源条目与已导入试卷分别保留。

听力支持题组字段 `audioUrl`（HTTP/HTTPS 或本站路径）。原创模拟卷提供明确标记的浏览器合成朗读，不是官方录音。合成朗读需要设备具有英语语音引擎；导入的真实音频可通过原生音频播放器播放。

来源及内容审查见 [docs/content-sources.md](docs/content-sources.md)。

## 评分与计时

完整六级练习按写作 15%、听力 35%、阅读 35%、翻译 15%计算百分制练习分。客观题由服务器依据答案自动判分，未答题为 0 分。作文和翻译保留参考答案、字数反馈与自评分；没有用字符匹配冒充自动评阅。当前没有接入可用的作文或翻译 AI 评分服务。

总分在主观题完成自评后生成。页面上的 710 分换算仅为 `练习百分制分数 × 7.1`，不是官方常模转换后的报道分，也不能用来保证正式考试成绩。[官方评分解释](https://cet.neea.cn/html1/folder/19081/5124-1.htm)

标准全卷总时长 130 分钟，建议写作 30、听力 30、阅读 40、翻译 30 分钟。[官方六级笔试结构](https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm)

开始后计时持续，离开页面计入当时所在大题。各大题可自由切换，分项时间是建议值，总时长是硬性限制。同一时间只允许一份活动答卷。截止时间之后的答案不会写入；未送达服务器的最后修改只保留在本地草稿中，不会篡改已交卷成绩。

## 数据与结构

运行时数据在 `data/learning.sqlite`，已从 Git 排除。浏览器本地草稿使用 `cet6-draft:<账号ID>:<答卷ID>`，管理员仍可读取升级前的旧格式草稿。删除浏览器缓存不会删除服务器中的已保存记录。

备份整套学习数据时，先停止本应用服务，再复制整个 `data/` 文件夹；恢复时也先停服务，再放回该目录。单词本可直接通过网页导出。

```text
src/                 React 学习页面及答题工作区
server/app.mjs       API、数据校验、计时和单词查询
server/store.mjs     SQLite 存储
server/scoring.mjs   客观判分与主观自评合并
server/analytics.mjs 学习诊断统计与可追溯证据
server/ai.mjs        AI 服务配置、异步分析与报告校验
server/seed.mjs      原创题库、来源入口及本地词典
tests/              服务端回归测试
public/images/      随项目保存的生成图像
docs/               来源和设计记录
```

内置词典提供中文释义；其他词汇通过 [Free Dictionary API](https://dictionaryapi.dev/) 查询英文释义。查询失败仍会保存单词，可在页面补充释义。CSV 导出包含 UTF-8 BOM，并转义可能被电子表格解释为公式的内容。

## 验证

```bash
npm test
npm run build
```

历史开发阶段曾使用 Playwright 检查桌面与手机页面、选项作答、作文和翻译输入、刷新恢复、计时、交卷、自评、单词收录和导出，以及离线批注与冲突处理。测试使用独立内存数据库；内部截图和设备 QA 脚本位于本地 `output/`，不在公开仓库中。这些历史记录不代表每次发布均已重新执行浏览器验收。

公开仓库可直接运行上面的自动化测试与构建。浏览器、OCR 工具及沙箱能力需在目标环境另行核验；桌面 WebKit 不等同于实体 iPad Safari / Apple Pencil 验证。

写作题目闪烁的回归检查应启用传统占位滚动条，而不是只用默认隐藏滚动条的无头浏览器。曾在 1180×820 下复现：文章区宽度在 589 / 573 像素之间反复切换，缩放比例随之振荡。现在通过 `scrollbar-gutter: stable` 和纸张外层裁切保持尺寸稳定；不支持 gutter 的浏览器使用固定纵向滚动条回退。该修复不改变原文的逻辑排版或已保存的笔迹坐标。

## 设计

按照用户指定的 [Taste Skill](https://github.com/leonxlnx/taste-skill) 中的字体层级、克制配色、避免卡片堆叠、完整交互状态和响应式规则制作；采用适合刷题工具的列表与固定答题区。详细取舍与图像记录见 [docs/design/README.md](docs/design/README.md)。

网站统一使用薄荷绿书本形象，包含执笔、阅读、词汇、复习、计时、诊断、整理和搜索 8 个主题。首页、登录注册、学习页面标题、空状态和交卷报告共用 `shared/illustrations.json` 素材表及尺寸规则；活跃答题区域不增加装饰，实际统计图不受影响。高清原图、压缩素材校验记录、生成提示词和使用规范见 [书本形象系列](docs/design/mascot-series/README.md)。

首页 9 个功能说明图标也使用同一角色系列；三个大幅产品展示下方分别补充阅读练习、手写批注、词卡积累的横向插画，采用无边框布局和按需加载。素材、生成提示词与校验记录见 [首页功能插画](docs/design/feature-illustrations/README.md)。操作按钮的功能图标保持原样。
