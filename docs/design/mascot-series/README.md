# 拾词书本形象系列

以用户提供的执笔书本形象为母版，使用内置 Image Gen 派生七个主题，包含后续新增的计时角色。原始形象和新图均保留高清 PNG；网页使用同尺寸的压缩 WebP，不覆盖原有素材。

## 素材与用途

| 素材名 | 道具 | 使用位置 |
| --- | --- | --- |
| writing | 黄色铅笔 | 登录、应用品牌、首页批注介绍；旧 3D 小屋贴纸源码保留 |
| reading | 打开的蓝色书本 | 试卷库标题、开始练习弹窗、注册、首页全卷练习介绍 |
| words | Aa 词汇卡 | 单词本标题及空状态、今日词汇、首页词汇介绍 |
| review | 练习记录夹板 | 学习记录标题、空状态、交卷报告 |
| timer | 浅蓝色计时钟 | 首页倒计时与答题进度说明 |
| insights | 放大镜和示意图板 | 学习诊断、错题复盘、统计和 AI 分析空状态 |
| organize | 分类文件夹 | 题库管理、管理后台 |
| search | 放大镜和空白纸 | 搜索无结果、通用空状态 |

素材注册表：`shared/illustrations.json`。前端统一通过 `src/Illustration.tsx` 使用；公开首页和登录页读取同一份注册表。公共尺寸规则在 `public/illustrations.css`，同时由应用和公开页面加载。

网页素材在 `public/images/mascots/`；本目录的 `originals/` 保留高清源文件，`assets.json` 记录尺寸、大小和 SHA-256。

首页单词本截图同步更新为 `public/images/feature-vocabulary-series.png`，展示同一套品牌和页面插图。截图来自独立内存数据库中的 8 个示例单词，不使用个人学习数据；原 `feature-vocabulary.png` 保留。

## 统一规则

- 保持薄荷绿色书本、白色纸页与手脚、黄色书签、黑色椭圆眼睛、珊瑚色鞋子，不为不同页面更换角色颜色或比例。
- 保持正面略偏侧的视角、左上方柔光、圆润材质、白色贴纸边缘及纯白底，不混用写实照片、不同光源或不同人物。
- 仅更换场景道具，保证脸部可见、四肢完整、图案在小尺寸下仍可辨认。
- 网页图统一为 512 × 512；图像使用 `object-fit: contain`，不得裁掉书签、鞋子或道具，也不拉伸比例。
- 标题图通常为 64px，手机为 52px；通用空状态为 108px，手机为 92px；诊断页紧凑空状态为 84px；品牌图为 40px。尺寸由共享组件控制。
- 每个页面只保留少量主题图；按钮、表格操作和编辑工具继续使用 Lucide 功能图标，不把角色图当作工具按钮。
- 活跃答题页面不增加装饰图。插画仅放在练习前、交卷后或非答题区域，不干扰文章、笔迹、答案和计时。
- 图板上的示意柱形属于插画道具，不代表用户数据；实际统计图、评分和诊断计算保持原样。
- 插画为装饰性内容，使用空 `alt` 和 `aria-hidden`；业务标题和按钮承担无障碍语义。预留稳定尺寸，图片加载或失败时不挤动文字。
- 新增素材必须先加入注册表，复核角色、配色、比例与留白，再在桌面、iPad 和手机视口中检查。

## 生成约束

初始七款的共用提示词及各主题补充保存在 `prompts.json`。后续计时角色和三幅首页横向场景的提示词见 [首页功能插画](../feature-illustrations/README.md)。所有图使用同一个原始角色作为参考，没有独立重新设计角色。白底是明确的纯白背景，不是透明通道，也不是模拟透明棋盘格。

公开版本的 `generatedSource` 使用仓库内原图的相对路径，不公开图像工具的本机缓存路径；原图文件及 SHA-256 记录保持不变。
