# PDF 导入与试卷分享

## 使用流程

1. 在「题库管理」或「真题练习」打开「导入试卷」，选择 PDF 并上传。
2. 文字版直接提取，缺少文字的扫描页使用中英文 OCR。转换在后台完成，可以取消；关闭弹窗不会删除原文件，可从「最近导入」继续。
3. 在校对页对照原页或提取文字，修改题目、选项、标准答案、参考答案、解析、原文和分值。原页支持放大。修改可保存为草稿；离开未保存草稿前会确认。
4. 勾选「已核对题目、选项与答案」后入库。题目可进入原有计时、作答、交卷和复盘流程。
5. 在题库管理勾选 PDF 试卷，或使用表头复选框全选当前列表中的可分享试卷，点击「分享已选」。创建分享前需要确认分享权限和文件隐私。
6. 接收方打开分享链接或粘贴分享码，登录后可多选或全选导入。新用户注册后也会回到对应分享。再次导入同一分享中的同一试卷会返回已存在的副本，不覆盖原数据。
7. 「分享记录」可以复制链接或撤销分享。撤销、到期或分享者账号停用后，链接不能继续导入；别人已经导入的副本不受影响。

## 识别边界

- 当前是本地 PDF 文字提取、OCR 和规则识别，不调用外部 AI，也不上传文档给第三方模型。
- 支持常见编号题目、A/B/C/D 选项、部分词库填空、阅读段落、写作/翻译及答案页。复杂分栏、特殊题号、公式、图表、错序文字或 OCR 错字需要人工核对。
- 未识别内容仍保存在原 PDF 和按页提取文字中；不会凭空生成缺失题目、答案或解析。完全未识别到题目时，可以在校对页新增题目。
- 缺失标准答案的选择题仍可选择作答，但使用人工评分。人工评分题不计入自动错题率、自动正确率或相应诊断；完成自评前不生成完整总分。
- 初始分值按题数均分为 100 分，校对时可修改。不是从 PDF 推导出的官方赋分或官方六级常模分数。年份优先从文件名识别，否则先使用导入年份；校对页可修改年份、月份与分类。
- PDF 本身不能提供外部听力录音。识别到听力部分会提示缺少音频，可在题组中补充自己有权使用的音频地址。
- 文件中的图片、超链接或脚本不会在解析时执行；原文件下载保留原字节，接收方应确认文件来源。

## 限额与隔离

| 项目 | 限额 |
| --- | --- |
| 单个 PDF | 20 MB、80 页 |
| 扫描/OCR 页 | 最多 40 页 |
| 总提取文字 | 60 万字符 |
| 转换总时长 | 8 分钟 |
| 每账号转换 | 同时 1 份 |
| 服务进程转换/预览 | 同时 2 个任务，等待队列最多 24 个 |
| 每账号原 PDF | 200 MB、200 个文件 |
| 每账号导入/分享记录 | 各最多 200 条 |
| 单次分享 | 1 至 100 份，题目快照最多 8 MB |
| 有效分享 | 每账号最多 100 条 |
| 分享有效期 | 7 天、30 天或长期 |

原 PDF、草稿、预览和导入结果都按账号隔离。原文件存入 SQLite BLOB，不放在公开静态目录。PDF 下载强制使用附件响应，页面预览是受控渲染的 PNG。分享只保存选中试卷的内容快照与 PDF 引用，不包含答卷、笔迹、单词本或 AI 设置。接收时创建自己拥有的 PDF 和题目副本，整批事务提交；失败会回滚。

分享码使用 24 字节随机数（32 字符 URL-safe 文本）。链接使用 `#share/...` 片段，服务端只在已登录用户显式解析/导入时接收分享码。分享列表和撤销接口仅限创建者。

PDF 处理通过 Bubblewrap 创建无网络的独立用户、进程和挂载命名空间；只读暴露系统程序、字体与库，宿主机仅允许写入本任务临时目录，其他临时写入位于隔离文件系统中。进程有内存、CPU、文件大小、句柄及墙钟超时限制，并清理临时文件。隔离组件不可用时不会降级为无隔离执行。操作系统和解析工具仍需正常维护安全更新。

## 运行依赖

Linux 服务端需要 Node.js 22.13+、Poppler、Tesseract、Bubblewrap 和 `prlimit`。Ubuntu/WSL 可安装：

```bash
sudo apt-get install poppler-utils tesseract-ocr tesseract-ocr-eng tesseract-ocr-chi-sim bubblewrap util-linux
tesseract --list-langs
```

需要内核允许创建相应命名空间。服务器当前已验证隔离提取、页面渲染与 `eng+chi_sim` OCR。普通浏览器无需安装这些程序。

工具依据：[Poppler](https://poppler.freedesktop.org/)、[Tesseract 命令行文档](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html)、[Bubblewrap 的隔离边界](https://github.com/containers/bubblewrap#sandbox-security)。

## 代码与测试

| 文件 | 职责 |
| --- | --- |
| `server/pdf-engine.mjs` | 隔离提取、OCR、页面渲染与任务限制 |
| `server/pdf-parser.mjs` | 文本转题目草稿、来源页与人工评分标记 |
| `server/library.mjs` | 原 PDF、导入任务、草稿、分享与接收接口 |
| `server/store.mjs` | Schema 5 的文档、任务、分享及导入回执表 |
| `src/PdfImport.tsx` | PDF 上传、状态与原页对照校对 |
| `src/PaperSharing.tsx` | 分享创建、接收、多选与撤销 |
| `tests/library.test.mjs` | 真 PDF/OCR、跨账号权限、评分与分享回归 |

```bash
npm test
npm run build
```

`tests/fixtures/` 中是自制测试文件，不是用户题库。`create_pdf_fixtures.py` 可用 ReportLab 和 Pillow 重新生成；运行正常测试无需 Python。升级仅新增表与字段支持，不重写旧答卷。备份整个 `data/` 或通过 SQLite 备份 API 保存数据库，即包含原 PDF 和分享记录。
